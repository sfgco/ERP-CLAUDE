# HR module — demo script per slice

Local: `npm run seed` then `npm run dev`; sample accounts use `Sample12345!` (see README). HR accounts (noura — HR manager, sara — HR officer) need an authenticator on first login (DECISIONS §2). Coverage: `docs/HR_COVERAGE.md`; plan: `docs/HR_PLAN.md`; decisions: `docs/DECISIONS.md` §21.

## H1 — التأسيس: audit of phase 1 and the gaps [HR §8 المرحلة الأولى] (built 2026-11-24, branch `hr-h1`)

Phase 1 already built the org structure, the employee file, the eight requests, contracts and documents, salary data, the export and the dashboard. H1 checked each bullet of HR §3.1, §3.3, §3.5, §3.9, §4, §5 and §6 against the code (`docs/HR_COVERAGE.md`) and closed the gaps below. Sites are still the sample ones (Q2 — the real list comes later).

1. **HR manager (noura)** → the menu «الموارد البشرية» now starts with **«الواجهة الرئيسية للموارد البشرية»** (`/hr`): work queues (requests awaiting HR, requests returned for completion, pending profile changes, secondments without a report), alerts (contracts / identities / documents expiring within 30 days, probation ending within 30 days, headcount) and shortcuts. Every card opens the records behind it. The blue note says which queues arrive with H2–H3.
2. **noura** → **«الهيكل التنظيمي»** (`/hr/org-chart`): one card per department with its units; employees nest under their direct manager with position, number, status and «n مرؤوس». Search by name / number / position highlights the matches; «طيّ الكل» / «توسيع الكل». Open the same page as **khalid** (Operations manager, no HR role): only himself and his direct reports; as **omar**: only himself.
3. **noura** → **«لوحة الموارد البشرية»**: the new row **«طلبات الموظفين خلال الفترة»** with the period switch (هذا الشهر / الشهر الماضي / آخر 90 يومًا) and the five cards of HR §5 — الجديدة، المعلقة، المعتمدة، المرفوضة، التي تحتاج إلى استكمال. Press each one: the requests list opens filtered (blue chips show the active filter, «إزالة الفلاتر» clears them). New cards: **«بحسب نوع التوظيف»** and **«مستندات تحتاج إلى تحديث»** (already expired). The branch, nationality and employment-type bars now link to the filtered directory.
4. **noura** → an employee file → tab «البيانات» → «تعديل»: the new field **«تاريخ الانضمام للتأمينات الاجتماعية»** (DECISIONS §21 Q8 — payroll will pick the GOSI rate group from it). Tab «الوظيفة والسجل» shows **«الوصف الوظيفي»** of the position and the site under **«موقع العمل»**. **omar** → «ملفي الشخصي» → the same date and description appear read-only.
5. **noura** → «تصدير البيانات»: in «الموظفون» the new card **«الموظفون المستهدفون»** — type two letters, pick employees (chips), preview → only those rows (HR §4 step 2). New resources: **«الوثائق والعقود القريبة من الانتهاء»** (filters: تنتهي خلال, النوع, القسم, employees) and **«طلبات الموظفين»** (number, type, employee, department, dates, state, pending party, decision and reason). The field «وجود تأمين طبي» is spelled as in the spec.
6. **omar** → «رفع طلب»: fill a leave request half-way and press **«حفظ كمسودة»**. Reopen «رفع طلب» → the banner «لديك مسودة محفوظة لطلب إجازة» with «استكمال المسودة» / «تجاهل المسودة». Resume, submit → the draft is gone.
7. **noura** → change omar's status to «موقوف» with a reason → omar and khalid get the notification «تم اعتماد تغيير وظيفي» with the old and new status and the reason (HR §3.7 — only promotions notified before).
8. **Archive** (HR §3.5 المرحلة الرابعة): approved and rejected requests move to «مغلق» by the daily job after `hr.requestAutoCloseBusinessDays` business days (default 5, «الإعدادات» → «الموارد البشرية»). The stage log and the action log show the system's «أرشفة تلقائية» row; the dashboard still counts them as approved / rejected in their period. To see it now, set the setting to 0 and run the daily jobs (`npm run dev` runs them on the schedule; the test `hr-h1.test.ts` exercises it directly).
9. **Admin** → «الإعدادات» → «الموارد البشرية»: the new auto-close setting. «وثائق الـ API» (`/api/v1/docs?prefix=/api/v1/hr`): every HR route with its permission, including `GET /hr/org-chart` and the request list's new `from / to / outcome / pending` parameters.
10. **Fresh database check**: `npm run seed` on an empty database creates the whole sample set or fails loudly (no block is skipped any more); CI runs the same through `apps/api/src/seed.test.ts`.

## H2 — التشغيل اليومي: schedules, GPS attendance, corrections, leave balances [HR §8 المرحلة الثانية] (built 2026-11-24, branch `hr-h2`)

Fresh database (`npm run seed`) gives thirty days of punches for every sample employee, field staff on two sample sites, opening leave balances for the year, and the four H2 sample requests. Everything marked «مؤقت حتى اعتماد الموارد البشرية» is a plan proposal awaiting the HR team (DECISIONS §21).

1. **omar** (field worker, phone width 375 px) → menu «الحضور والانصراف» (`/me/attendance`): the live Riyadh clock, today's schedule «الدوام الميداني · 07:00 – 15:00», the two sites he may punch from, the month cards (hours, present, late, absent, missing, overtime) and the history. Press **«تسجيل الحضور»**: the browser asks for the location; inside a sample site the badge says «داخل النطاق: تبعد n م عن …» and the day becomes «حاضر» / «متأخر» with the server's time. Press it again → «سجّلت الحضور مسبقاً»; «تسجيل الانصراف» closes the day and shows the hours. Deny the location → «تعذر تحديد الموقع — حاول مرة أخرى أو اطلب استثناءً». (To see a refusal for distance, use the browser's location override far from Dammam.)
2. **omar** → the three buttons under the card: **«طلب تعديل بصمة أو معالجة تسجيل مفقود»** (day, kind, correct time, reason — within 7 days), **«طلب استثناء من النطاق الجغرافي»** (period ≤ 5 days, scope), **«طلب عمل إضافي»** (today onwards, start / end). Each opens «رفع طلب» with the type preselected; the route line says where it goes.
3. **khalid** (Operations manager) → **«حضور فريقي»** (`/manager/attendance`): the team's days for a period, status badges, lateness and hours — no coordinates anywhere. «طلبات فريقي» shows omar's correction «بانتظار موافقة المدير»; approve it → it goes to HR. Approve **yousef's overtime** → it is «معتمد» at once (the manager is the final approver, Q16) and never reaches the HR queue.
4. **sara** (HR officer) → «طلبات الموظفين»: approve omar's correction → open `/hr/attendance`, filter his day: a new punch `source: correction` appears next to the original, the day is recomputed («حاضر» with the hours). Open **«البصمات»** of any day: HR sees the coordinates, the site, the distance and the source; the view is written to the audit log as sensitive.
5. **noura** → **«سجل الحضور»** (`/hr/attendance`): filters (period, status, department, branch, employee, «الاستثناءات فقط»), the totals strip, **«إدخال بصمة يدوياً»** (HR only, reason required, audited) and **«إعادة الاحتساب»**. The same page opens from every attendance card of the dashboard.
6. **noura** → **«الجداول والورديات»** (`/hr/shifts`): «الدوام الأساسي» (default, amber «مؤقت» note), «الدوام الميداني», the sample evening rotation; edit a shift → a new version (versions kept); **«إسناد موظف»** to a shift with sites from a date → the previous assignment closes the day before and the days are recomputed; «سجل الإسناد» per employee.
7. **noura** → **«أرصدة الإجازات»** (`/hr/leave`): balances per employee and type (استحقاق / مستحق / مأخوذ / رصيد, article numbers, «مؤقت» badge on the cooperative's own types), **«إضافة رصيد أو تسوية»** with a reason, **«استيراد أرصدة افتتاحية»** (CSV by employee number), and the ledger behind each balance. **omar** → «رفع طلب → إجازة سنوية» for more days than his balance → refused with the available balance; a sick leave over the balance is accepted and flagged for HR; a «مولود» leave asks for the birth date and must start within 7 days of it.
8. **Employee file** → tabs **«الحضور»** (days of a window with totals) and **«الإجازات»** (balances and ledger for a year).
9. **noura** → «لوحة الموارد البشرية»: the new row **«الحضور والانصراف خلال الفترة»** — الغياب، التأخير، إجمالي ساعات العمل، عدم تسجيل الحضور أو الانصراف، في إجازة اليوم — each drilling down to the attendance log; «تصدير البيانات» lists the nine new resources (سجل الحضور والانصراف، سجل التأخير، سجل الغياب، ساعات العمل والعمل الإضافي، طلبات تعديل البصمة، التقرير الشهري لكل موظف، إجمالي الحضور لكل قسم أو فرع، أرصدة الإجازات، الإجازات المعتمدة) with period / department / branch / employee filters.
10. **Reminders**: the frequent job notifies an employee who has not checked in 30 min after the start and one who has not checked out 60 min after the end («لم تسجّل الحضور أو الانصراف», once each). **Admin** → «الإعدادات → الموارد البشرية»: the attendance and leave settings with their descriptions; provisional ones carry the amber badge and a **«تأكيد الاعتماد»** button that clears it once the HR team decides.
